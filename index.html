Casualties Unknown Wiki MCP

A public remote MCP server for the Casualties Unknown fan wiki database. Search and read items, liquids, moodles/status effects, recipes and more — every entry returned with its sprite image. Free to use, no sign-up, no API key.

MCP endpoint

POST https://casualties-unknown-wiki-mcp.vercel.app/mcp
Stateless Streamable HTTP transport — JSON-RPC 2.0 in, application/json out.

Connect your client

Any MCP client that supports remote (HTTP) servers can use it directly:

{
  "mcpServers": {
    "casualties-unknown": {
      "url": "https://casualties-unknown-wiki-mcp.vercel.app/mcp"
    }
  }
}

Clients that only speak stdio (or that require an SSE transport) can bridge to it with a proxy such as mcp-proxy or npx mcp-remote https://casualties-unknown-wiki-mcp.vercel.app/mcp.

Tools

ToolWhat it doesExample arguments
cu_search Search everything by name across all sections. {"query": "stroke"}
cu_item Item page plus its liquid effects in one result, with sprite. {"name": "sodium nitroprusside"}
cu_status Moodle / status effect lookup, with icon. {"name": "stroke"}
cu_get Read any entry by section and slug. {"section": "liquids", "slug": "procoagulant"}

Source & code

Source code (Python, stdlib + optional Pillow) is on GitHub: agentpixelated/casualties-unknown-wiki-mcp. The same code also runs locally over stdio — see the README there.

All data comes from the unofficial fan database casualtiesunknowndb.com, fetched live on demand — nothing is bulk-mirrored. This project is not affiliated with the game developer. Game data and sprites belong to their respective owners; this is a fan tool.
